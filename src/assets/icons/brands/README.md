# Brand icons

SVGs from [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons): LinkedIn, GitHub, Gmail (for the Gmail contact address), Instagram, Steam, and Buy Me a Coffee.

The original SVG geometry is retained. Icons are served locally and rendered as CSS masks so they inherit the existing theme colors. No external icon service is needed at runtime. The upstream CC0 license is included in `LICENSE.md`; brand marks remain the property of their owners.
